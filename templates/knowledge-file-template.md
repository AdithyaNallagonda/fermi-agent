# Knowledge File Template
Copy this skeleton for any new `knowledge/<area>/<tech>.md`, then add a row to `knowledge/INDEX.md`.
```
# <Technology>
Last reviewed: YYYY-MM | Load when: <...>
## Mental model
## Core concepts
## When to use / when not
## Design patterns
## Performance & scaling
## Security
## Cost levers
## Gotchas & anti-patterns
## Interview / exam angles
## Cross-cloud equivalents
## References (official docs)
```
Then add a row to this INDEX.
